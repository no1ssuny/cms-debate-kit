# CMS Debate Kit

Create a reusable, classroom-ready debate package through this sequence:

`excerpt -> debate topic -> evidence cards -> worksheet and rubric -> citation audit`

## Establish scope before writing

Inspect the current project without changing files. Identify the excerpt, any debate rules or forms, the project root, and whether a `결과물` folder exists.

Before creating, moving, or editing anything, show the user:

- the work to be performed;
- every target file;
- the expected result;
- each absolute save path under the project's `결과물` folder.

Wait for explicit approval. Modify only the approved targets and request approval again for additional changes.

## Preserve source material

Treat excerpts, debate rules, forms, and other supplied source files as originals. Never edit, delete, rename, move, or overwrite them unless the user separately and explicitly authorizes that exact change.

Save every newly created document, code file, and report in the project-root `결과물` folder. If the folder must be created, include that action in the approval plan. Avoid unrelated files even when discovered during inspection.

## Enforce the evidence boundary

Use only the supplied excerpt as evidence. Do not present memory of the full book, summaries, reviews, web sources, or general background knowledge as support for a claim.

When the excerpt does not support a requested fact, interpretation, quotation, or argument, write exactly:

`발췌문에서 확인 불가`

Do not fill gaps by guessing. A claim may be framed as a question or student hypothesis only if it is clearly labeled as such and is not represented as excerpt-based evidence.

## Build the package

1. Establish a paragraph map for the excerpt. Preserve existing paragraph numbers. If none exist, create a derived, numbered working copy in `결과물` after approval; do not add numbers to the original.
2. Draft a concise, genuinely debatable topic that the excerpt gives students enough material to discuss from more than one position. If the excerpt cannot support both sides, state `발췌문에서 확인 불가` and explain what evidence is missing.
3. Create evidence cards. Each card should identify the side or claim, reproduce a relevant excerpt verbatim, give its paragraph number, and explain how that quotation supports the claim. Keep inference distinct from what the text explicitly says.
4. Create the student worksheet from the approved topic and evidence cards. Provide space to state a position, select and explain quotations, consider a counterargument, and prepare a response.
5. Create a rubric aligned to the worksheet. Assess at least textual accuracy, relevance of evidence, reasoning, counterargument or response, and citation completeness. Do not reward unsupported outside knowledge as textual evidence.
6. Run a citation audit across the topic, cards, worksheet, rubric examples, and any teacher notes. Compare every quotation character-for-character with the excerpt and confirm its paragraph number. Record each item as verified or needing correction. Replace unsupported assertions with `발췌문에서 확인 불가` rather than inventing support.

## Citation requirements

- Quote the original wording exactly; do not silently modernize, summarize, correct, or splice quoted text.
- Put the paragraph number next to every quotation.
- Use ellipses or brackets only when the excerpt and the user's citation convention allow them, and never let them change the meaning.
- Label paraphrases as paraphrases and still attach the supporting paragraph number.
- If wording or paragraph location cannot be verified, do not treat it as a valid citation; mark it `발췌문에서 확인 불가`.

## Finish and report

Verify that every created artifact is inside `결과물`, every cited passage exists verbatim in the excerpt, and no original changed. Report the changes, the number of files created or modified, and every final absolute path.
